# Last Bib Radar

Marathons, half marathons and 10Ks across Southeast Asia and India with registration open or opening soon.
Search near a place, filter by region, country, date and distance. Sorted by race relevance.

- Site: `index.html` (GitHub Pages, branch `main`, root)
- Data: `data/races.json`, alerts: `data/news.json`
- Updated daily at 07:00 Bangkok time by a scheduled task following `UPDATE.md`
